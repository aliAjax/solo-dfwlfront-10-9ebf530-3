# 油站高峰排队沙盘

面向油站值班主管的高峰排队仿真沙盘：设定营业参数后按时间顺序逐车模拟分配泵岛，
观察排队、等待、泵岛占用与时间轴，并可保存 3 套方案并排比较。

- 行业：石油
- 技术栈：React、Vite、TypeScript、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 场景验证：`npm run verify`（正常 / 边界 / 故障 / 校验拦截，共 40+ 项断言）

## 功能

- **可配置参数**：营业时段、泵岛数量、分时到车量（按小时分段）、单车服务时长上下限、
  随机种子、单泵故障时段（可多条）。
- **确定性仿真**：同一配置 + 同一种子重复运行结果完全一致，结果区展示“结果指纹”便于核对。
- **故障约束**：故障时段内停用泵完全不参与服务（任何服务区间都不与故障区间重叠）。
- **结果失效**：任何配置变更立即使旧结果失效（变灰锁定，需重新运行）。
- **校验拦截**：空值、负数、服务时长上限小于下限、到车量全为零等情况下不能运行，
  并逐条说明原因。
- **方案对比**：最多保存 3 个方案（localStorage），并排比较平均等待、最长队伍、
  泵岛利用率、完成车数等指标，自动高亮每行最优值。

## 仿真模型约定

- 到车：每个时段内按种子均匀撒点；服务：单队列多服务台，严格 FIFO，
  队首车辆分配给“编号最小且能完整容纳其服务时长”的空闲泵。
- 时间轴终点取营业结束与最后一车完成时间的较晚者（可能产生营业外加班）。
- 方案数据保存在浏览器 localStorage，无需后端。
